# Biomechanics — Body Segment Analysis

This repository contains a simple interactive tool for estimating body segment lengths from a single image. It was created as an assignment submission for a biomechanics course.

Author: Sameer Wanjari (21174028)
Branch: Engineering Physics

**What it does:**
- Let the user pick anatomical keypoints on a photo using an interactive OpenCV window.
- Compute pixel distances between defined keypoints and convert them to real-world lengths using a user-supplied actual height.
- Save results to `keypoints_coordinates.txt` and `segment_lengths.txt` and produce an annotated image (`annotated_output.jpg`).

**Files of interest:**
- `main.py`: Main analysis script (interactive). Edit the `ACTUAL_HEIGHT` and `IMAGE_FILE` constants at the bottom to run on your image.
- `keypoints_coordinates.txt`: Saved coordinates after a run.
- `segment_lengths.txt`: Saved numeric results and summary after a run.
- `segment_lengths.txt` and `keypoints_coordinates.txt` are overwritten on each run.
- `requirements.txt`: Python dependencies.
- `keypoints_coordinates.txt` and `segment_lengths.txt` (example outputs generated by the script).

**Requirements**
- Python 3.8+ (tested on Windows)
- `opencv-python`, `numpy`

Install dependencies (recommended in a virtual environment):

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**Usage**
1. Place your input image (e.g. `body_photo.jpg`) in the repository folder or update the `IMAGE_FILE` path in `main.py`.
2. Set your actual height (in meters) by editing the `ACTUAL_HEIGHT` value in `main.py`.
3. Run the script from the command prompt:

```
python main.py
```

Interactive instructions:
- The script will open a resizable OpenCV window and prompt you to select a sequence of anatomical keypoints. The required points (in order) are printed to the console and shown in the GUI.
- Click the left mouse button to record each point. After selecting all points, press ESC or close the window to finish.

Outputs created by a successful run:
- `keypoints_coordinates.txt` — list of selected keypoint names and coordinates.
- `segment_lengths.txt` — a human-readable report with the computed real-world lengths (m) and pixel lengths (px).
- `annotated_output.jpg` — the input image annotated with selected points and segment lines.

**Data / Keypoints used**
The script expects several anatomical landmarks such as `CV7`, `L3/L4`, `left_shoulder`, `left_elbow`, `left_wrist`, `right_shoulder`, `right_elbow`, `right_wrist`, `left_hip`, `left_knee`, `left_ankle`, `right_hip`, `right_knee`, `right_ankle`, `head_top`, and `heel`. These names appear in the saved `keypoints_coordinates.txt` and are used to compute segment lengths.

**Notes & troubleshooting**
- If OpenCV cannot open a window, ensure your Python environment supports GUI windows (not headless). On some remote setups you may need to run locally.
- If the script prints "Error: Image file 'body_photo.jpg' not found.", update `IMAGE_FILE` or place the image in the repository directory.
- The script uses the pixel distance between `head_top` and `heel` as the pixel height reference for scaling. Ensure those two points are selected accurately.

**Customization**
- To change which segments are computed, edit the `self.segments` dictionary inside `BodySegmentAnalyzer` in `main.py`.
- To change the required keypoint order or names, edit `self.required_points`.
